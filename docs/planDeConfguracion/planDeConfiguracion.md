## 1. Introduccion
---

### 1.1 Alcance

El plan de gestion de configuacion para el proyecto Megastore define procedimientos 
necesarios para la gestion de cambios y la configuracion del sistema.

---

### 1.2 Definiciones, Acronimos y Abreviaturas

 * <b>Git</b>: Sistema de control de versiones
 * <b>GitHub</b>: Servidor remoto donde se aloja el repositorio
 * <b>Branch</b>: Rama del proyecto donde se trabaja sobre una o mas caracteristica en concreto
 
 ---

 ## 2. Gestion de configuracion del sistema

 ---

### 2.1 Ambiente de computacion y herramientas

Herramientas utilizadas:

 * <b>Visual Studio Code</b> (Editor de codigo)
 * <b>Postman</b> (Pruebas manuales de las apis)
 * <b>XAMPP</b> para la gestion de base de datos MySQL/MariaDB
 * <b>Git</b> y <b>Github</b> para control de versiones y alojamiento remoto del repositorio.

 ---

 ### 2.2 Organizacion y responsabilidades

El eequipo de desarrollo es responsable de implementar, revisar y gestionar cambios, y deslpegar el sistema. El lider de proyecto realizara supervision de las aprobaciones y liberacion de nuevas versiones del ecommerce.

El equipo de desarrollo sera el encargado de revisar codigo de los integrantes y garantizar su correcto funcionamiento y calidad.

---

## 3. Programa de la Gerencia de Configuración del Sistema

---

### 3.1 Control de cambio y configuracion

Procesamiento y aceptacion de un cambio:

Los cambios en la configuracion del proyecto se hacen con el fin de corregir cualquier tipo de error agregar nueva funcionalidad, los cuales son mostrados en formato de Pull Request sobre una branch basada en la feature modificada, y revisado por otros compañeros del equipo de desarrollo que aprueban dichos cambios.

---

### 3.2 Estado de la configuracion

Las auditorias se realizan al final de una entrega del proyecto verificando cambios y estabilidad del proyecto segun los objetivos planteados.
